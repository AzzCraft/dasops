# Product Repo Verify Policy

Product repos generated by `dasops` must fail closed.

## Minimum Checks

- required governed docs exist
- copied standard text is rejected
- `tooling_lock.json` exists
- `local_extension_manifest.json` exists
- `openspec/config.yaml` exists
- stray `tasks.md` files are rejected

## Template Parity

The following surfaces must describe the same supported behavior:

- CLI help and docs
- GUI form copy
- template README and verify scripts
- worker/orchestrator prompts

Any drift between those surfaces is a governance defect.
