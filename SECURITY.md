# Security Policy

Report vulnerabilities privately through the [GitHub security advisory
form](https://github.com/AzzCraft/dasops/security/advisories/new). Do not post
exploit details in a public issue. Maintainers aim to acknowledge reports within
five business days; supported releases are the latest published v1.x version.
