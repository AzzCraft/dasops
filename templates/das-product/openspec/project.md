# DAS + OpenSpec Project Overview

This repository is a workflow + tooling template that combines:

- DAS governance (Master Doc, UI Spec, Contracts, Verify)
- OpenSpec change folders (spec-driven development)

The actual application code is expected to be created by humans or AI workers
based on the docs and change-folder artifacts.

## Canonical docs
- docs/master_doc.md
- docs/ui_spec.md

## OpenSpec change folders
- openspec/changes/<change-id>/
